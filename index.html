Module Bay Optimizer

Lay out machine modules for Probably Stolen and see exactly what the bay gives you. The math follows the game's own code: shape bonuses, Receiver, Top/Side Mount, Support nodes and Negative Feedback.

Goal, in order of priority
The optimizer works down the list: it gets line 1 as good as it can (or to your target), keeps that, then improves line 2, and so on. Readings use the machine's real rules, so thresholds such as water grades, purity steps and cycles per job are handled for you. Mark a module Must use to force it in somewhere, or Lock it to keep it exactly where it sits.

My modules

Import modules from your save

Reads a save file in this browser only (nothing is uploaded) and replaces My modules with every module in it: the ones installed in your machines, with their finished jobs, and the loose ones in your inventories. Each save slot is one file in %USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\: save_0.es3, save_1.es3 and so on. Paste that folder path into the file picker's address bar.
